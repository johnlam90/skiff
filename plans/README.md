## Findings considered and rejected

Recorded so nobody re-audits them:

- **Off-main-loop `editor.Buffer` reads**: all 14+ goroutine sites traced;
  every one captures plain values on the loop. The CLAUDE.md rule holds.
- **`a.screen.Clear()` per frame**: tcell's diffing renderer makes it
  cost-free over the wire; not a finding.
- **`HighlightWindow` full-file style slice**: the doc comment weighs the
  alternative and picks correctly; not worth doing.
- **Hostile `.gitignore` patterns panicking the editor**: RE2 (no
  catastrophic backtracking), guarded indexing, byte-equality cache; safe.
- **Symlinked dirs browsing outside the project root**: intentional,
  loop-detected, read-only; same behavior as other editors.
- **Formatter child inheriting the environment**: inside the recorded
  trust tradeoff.
- **Man page / shell completions / CHANGELOG.md / JSON `--version`**:
  CLI surface is six lines, the shell completes paths natively, GitHub
  Releases notes are generated by goreleaser, and `--version` output is
  already machine-parsed by the brew test.
- **Direction options surfaced but not planned** (maintainer's call,
  ask for a design/spike plan if wanted): dirty-buffer autosave & crash
  recovery; hunk-level staging in the git panel; drag-and-drop tree moves.
